# University_Student_ABM

This model simulates the process of university admissions through both university and student agents. It varies information transparency on student tuition as well as the degree of revenue-incentives for universities.

The following files are utilized to run the model:
- model.py
- agents.py
- app.py can be used to vizualize the model

For initial results see the following:
- analysis.ipynb contains the batch-run code as well as the preliminary analysis of results
- batch_runs.csv contains the results of those batch runs
